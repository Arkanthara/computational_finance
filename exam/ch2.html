Histoire — Pourquoi tout cela ?

Genève, janvier 2012, 8h47.

Antoine, analyste quantitatif junior dans une banque privée genevoise, reçoit son premier vrai défi. Sur son écran : soixante-dix cotations EUR/USD quotidiennes. Son responsable pose la question, apparemment simple : « Y a-t-il un pattern exploitable ici ? Peut-on prédire le prochain mouvement ? »

Antoine regarde la série. Il voit le taux passer de 1.27 à 1.33, puis se stabiliser, puis corriger légèrement. Il calcule la moyenne : 1.30. L'écart-type : 0.015. Utile… mais terriblement insuffisant pour répondre à la question posée.

Problème 1 — La non-stationnarité. Ces prix EUR/USD montent sur la période — leur moyenne n'est pas constante dans le temps. Appliquer un modèle directement sur les prix, c'est comme mesurer la vitesse d'une voiture en regardant uniquement sa position. On perd l'essentiel.

Solution : Antoine calcule les rendements quotidiens $r_t = (X_t - X_{t-1}) / X_{t-1}$. La nouvelle série oscille autour de zéro, avec une variance stable. Elle est (faiblement) stationnaire.

Problème 2 — La structure cachée. Ces rendements contiennent-ils une mémoire ? Le rendement d'aujourd'hui dépend-il de celui d'hier ? D'il y a deux jours ?

Solution : Il calcule la fonction d'autocorrélation (ACF). Les barres restent dans l'intervalle de confiance — très peu de structure. Un AR(1) donne $\hat{\varphi}_1 \approx -0.125$ : légère tendance mean-reverting, mais faible pouvoir prédictif. Le marché EUR/USD à court terme ressemble à un bruit blanc.

La leçon : un bon modèle de série temporelle nécessite trois étapes incontournables.

Les 3 piliers du workflow ① Stationnariser les données (rendements, différenciation, log-transformation)
② Analyser l'ACF pour détecter la structure temporelle et choisir l'ordre
③ Estimer et valider le modèle AR/MA/ARMA avec les critères AIC/BIC

Résumé exécutif — 30 secondes

Définition centrale
Une série temporelle (*time series*) est une suite d'observations indexées dans le temps $\{X_{t_i}\}$. Les modèles autorégressifs (*autoregressive models*) — AR(p), MA(q), ARMA(p,q) — modélisent $X_t$ comme une fonction linéaire de ses valeurs passées et/ou d'un bruit aléatoire. Leur application rigoureuse exige que la série soit stationnaire (*stationary*), c'est-à-dire à moyenne et autocovariance stables dans le temps. La fonction d'autocorrélation (*Autocorrelation Function*, ACF) révèle la structure temporelle de la série et guide le choix du modèle.
Concept clé

Lag τ

Décalage temporel entre deux observations. $\tau = 1$ signifie « hier » par rapport à « aujourd'hui ».

Prérequis

Stationnarité faible

Moyenne constante + autocovariance qui ne dépend que du lag τ, pas du temps absolu.

Outil diagnostique

ACF

Corrélation de $X_t$ avec lui-même décalé de τ. Révèle les patterns cachés dans la série.

Modèle phare

AR(1)

$X_t = c + \varphi_1 X_{t-1} + \varepsilon_t$. Un seul paramètre, riche en propriétés analytiques.

01

Réponse modèle d'oral — 3 minutes

Une série temporelle est une séquence d'observations réelles indexées dans le temps, comme les cours boursiers ou les taux de change. L'objectif fondamental est de comprendre la structure de cette série — comment le passé influence-t-il le futur ? — et éventuellement de prédire des observations futures.

Pour modéliser correctement une série temporelle, le prérequis essentiel est la stationnarité. Une série est faiblement stationnaire si sa moyenne est constante et si son autocovariance ne dépend que du lag τ, pas du temps. En pratique, les prix financiers ne sont jamais stationnaires — ils dérivent dans le temps. On travaille donc sur les rendements, qui sont généralement stationnaires. Ce fait peut être vérifié formellement avec le test Augmented Dickey-Fuller.

L'outil central pour analyser la structure d'une série stationnaire est la fonction d'autocorrélation (ACF). Elle mesure la corrélation linéaire entre $X_t$ et $X_{t+\tau}$ pour différents lags. Une ACF à décroissance lente et positive indique une tendance ; une ACF avec alternance de valeurs positives et négatives signale un comportement contre-tendanciel, dit *mean-reverting*.

Sur la base de l'ACF, on choisit la famille de modèle. Un modèle AR(p) exprime $X_t$ comme combinaison linéaire de ses $p$ valeurs passées plus un bruit blanc. Un modèle MA(q) utilise les $q$ erreurs passées. Le modèle ARMA(p,q) combine les deux. Pour le modèle AR(1), on peut démontrer analytiquement que le coefficient $\varphi_1$ est égal à la corrélation au lag 1, que la variance vaut $\sigma_\varepsilon^2 / (1-\varphi_1^2)$, et que la condition de stationnarité est $|\varphi_1| < 1$.

Enfin, pour sélectionner l'ordre optimal du modèle, on utilise les critères AIC et BIC, qui pénalisent la complexité pour éviter le surapprentissage. Le BIC pénalise davantage les modèles à grand nombre de paramètres.

02

Séries temporelles — Les bases

Définition formelle

Une série temporelle univariée (*univariate time series*) est une suite d'observations réelles :

Définition — Time Series
$$X(t_i) \in \mathbb{R}, \quad t_i \text{ occurrences ordonnées}$$

L'ordre est crucial : contrairement à la théorie de l'information où les occurrences peuvent être réordonnées, ici la séquence temporelle est l'information elle-même. Le lag (ou décalage temporel) $\tau$ est le temps entre deux observations. La variable retardée $X_{t-\tau}$ est appelée lagged variable.

Schéma 1 — Anatomie d'une série temporelle & notion de lag

Objectifs d'un modèle de série temporelle

Le cours souligne qu'un modèle peut avoir plusieurs objectifs, parfois contradictoires :

ObjectifDescriptionExemple d'usage
IdentificationIdentifier les éléments structurels importantsDétecter la saisonnalité dans les volumes de trading
ExplicationComprendre comment le passé influence le présentMesurer l'inertie des taux d'intérêt
ModélisationReprésenter l'état actuel de façon synthétiqueCalibrer un modèle de volatilité
PrédictionPrévoir les observations futuresAlgorithme de trading
Point crucial (examen)
Un modèle peut être excellent pour expliquer mais médiocre pour prédire. Ces deux objectifs ne requièrent pas les mêmes critères d'évaluation. Ne pas les confondre !
03

Stationnarité

Pourquoi la stationnarité est indispensable ?

On ne peut pas appliquer directement un modèle autorégressif à n'importe quelle série. Trois types de non-stationnarité doivent être détectés et corrigés :

Schéma 2 — Les trois ennemis de la stationnarité

Ces trois problèmes rendent les paramètres estimés instables, les tests statistiques non fiables, et les prédictions invalides. C'est pourquoi la stationnarité est un prérequis, pas une option.

Définitions formelles

Stationnarité stricte (*Strict Stationarity*)

Un processus $\{X_t\}$ est strictement stationnaire si sa distribution jointe est invariante par translation temporelle :

Définition — Strict Stationarity
$$F(X_{t_1+\tau}, \ldots, X_{t_n+\tau}) = F(X_{t_1}, \ldots, X_{t_n}) \quad \forall \tau, n$$

Cette condition est très forte — elle impose que toute la distribution reste inchangée par translation. En pratique, elle est quasi impossible à vérifier sur des données réelles.

Stationnarité faible (*Weak / Covariance Stationarity*) ← la pratique

Un processus est faiblement stationnaire si deux conditions sont satisfaites :

Définition — Weak Stationarity
$$\text{(a) Moyenne constante :} \quad \mathbb{E}[X_t] = \mu \quad \forall t$$ $$\text{(b) Autocovariance dépend uniquement de } \tau : \quad \text{Cov}(X_t, X_{t+\tau}) = \gamma(\tau) \quad \forall t, \tau$$
Intuition
Imaginez une rivière en état d'équilibre : le débit moyen ne change pas selon la saison (moyenne constante), et les tourbillons à un point ont toujours la même relation avec les tourbillons à 100 mètres en aval (autocovariance stable). C'est ça, la stationnarité faible.

Les transformations principales sont :

  • Rendements simples : $r_t = (X_t - X_{t-1}) / X_{t-1}$ — élimine la tendance, stabilise la variance
  • Log-rendements : $r_t = \ln(X_t / X_{t-1})$ — atténue l'effet des changements de volatilité (hétéroscédasticité)
  • Différenciation : $\Delta X_t = X_t - X_{t-1}$ — supprime une tendance linéaire
  • Décomposition saisonnière : supprimer la composante saisonnière identifiée
Exemple empirique du cours — EUR/USD 2012
Les prix EUR/USD (p-value ADF > 0.15) : non stationnaires. Les rendements quotidiens (p-value ADF = 0.00) : stationnaires. Ce résultat est typique de tout actif financier — c'est pourquoi on travaille systématiquement sur les rendements.

Test Augmented Dickey-Fuller (ADF)

Le test ADF (*Augmented Dickey-Fuller Test*) teste formellement l'hypothèse nulle $H_0$ : "la série a une racine unitaire" (non-stationnaire). Si la p-value est inférieure à 0.05, on rejette $H_0$ et on conclut à la stationnarité. En dessous de 0.05 = stationnaire ✓

04

Autocorrélation — ACF

Rappel : corrélation entre deux variables

Corrélation de Pearson
$$\text{Cor}(X, Y) = \frac{\text{Cov}(X,Y)}{\sqrt{\text{Var}(X)\cdot\text{Var}(Y)}} = \frac{\mathbb{E}[(X-\mathbb{E}[X])(Y-\mathbb{E}[Y])]}{\sqrt{\mathbb{E}[(X-\mathbb{E}[X])^2]\cdot\mathbb{E}[(Y-\mathbb{E}[Y])^2]}}$$

Définition de l'autocorrélation

L'autocorrélation (*autocorrelation*) est la corrélation d'une variable avec elle-même à un décalage temporel $\tau$ :

ACF — Autocorrelation Function
$$\text{ACF}(\tau) = \rho_\tau = \text{Cor}(X_t, X_{t+\tau}) = \frac{\mathbb{E}[(X_t - \mu)(X_{t+\tau} - \mu)]}{\sigma^2}$$ $$\text{(sous hypothèse de stationnarité faible : } \mu_t = \mu_{t+\tau} = \mu \text{ et } \sigma_t = \sigma_{t+\tau} = \sigma\text{)}$$

L'ACF est une fonction du lag τ — elle décrit la structure complète de dépendance temporelle de la série. C'est l'outil diagnostique fondamental avant toute modélisation.

Guide de lecture de l'ACF

Schéma 3 — ACF : trois profils typiques et leur interprétation

Intervalle de confiance de l'ACF

Pour $n$ observations, l'intervalle de confiance approximatif à 95% est :

Confidence Interval — ACF
$$\text{IC}_{95\%} \approx \pm \frac{1.96}{\sqrt{n}}$$

Toute barre de l'ACF dépassant cet intervalle est considérée statistiquement significative. C'est la ligne bleue en pointillés dans tous les graphes ACF du cours.

Exemple remarquable — VIX (cours)
Les rendements du VIX entre 2010 et 2013 montrent des autocorrélations significativement négatives au lag 1. Cela signifie : si le VIX monte fortement aujourd'hui, il tend à baisser demain. Ce comportement mean-reverting du VIX est un fait empirique bien établi en finance.
05

La famille AR / MA / ARMA

Les trois modèles fondamentaux

AR(p) — Autoregressive Modelordre p
$$X_t = c + \sum_{i=1}^{p} \varphi_i X_{t-i} + \varepsilon_t$$

Le présent est une combinaison linéaire des $p$ valeurs passées plus un bruit. Les $\varphi_i$ sont les coefficients autorégressifs. La mémoire du modèle porte sur les valeurs passées elles-mêmes.

Usage typique

Séries avec inertie (PIB, volatilité)

Estimation

AR(1) : analytique. AR(p>1) : maximum de vraisemblance

MA(q) — Moving Average Modelordre q
$$X_t = \mu + \varepsilon_t + \theta_1\varepsilon_{t-1} + \cdots + \theta_q\varepsilon_{t-q}$$

Le présent est la moyenne plus une combinaison linéaire des $q$ erreurs passées. La mémoire porte sur les chocs passés (non observés), pas sur les valeurs elles-mêmes.

Usage typique

Chocs transitoires, processus à mémoire courte

Propriété clé

Toujours stationnaire (contrairement à AR)

ARMA(p,q) — Combined Modelordre p, q
$$X_t = c + \varepsilon_t + \sum_{i=1}^{p} \varphi_i X_{t-i} + \sum_{i=1}^{q} \theta_i \varepsilon_{t-i}$$

Combinaison des deux : valeurs passées ET erreurs passées. Modèle le plus général et le plus flexible de la famille. Avec peu de paramètres, il peut capter des structures complexes.

Cas limites

AR(p) = ARMA(p,0) ; MA(q) = ARMA(0,q)

Extension

ARIMA pour séries non-stationnaires (I = Integrated)

06

AR(1) — Analyse complète

Le modèle AR(1) est le plus simple des modèles autorégressifs et permet d'établir des résultats analytiques fermés. C'est le point de départ de toute l'analyse.

Modèle AR(1) — Définition
$$X_t = c + \varphi_1 X_{t-1} + \varepsilon_t, \quad \varepsilon_t \sim \mathcal{N}(0, \sigma_\varepsilon^2) \text{ i.i.d.}$$

① Calcul de la moyenne

Si le processus est stationnaire, sa moyenne est constante : $\mathbb{E}[X_t] = \mathbb{E}[X_{t-1}] = \mu$. On prend l'espérance des deux membres :

Dérivation — Moyenne d'un AR(1)
$$\mu = \mathbb{E}[c + \varphi_1 X_{t-1} + \varepsilon_t] = c + \varphi_1 \mu + \underbrace{\mathbb{E}[\varepsilon_t]}_{=0}$$ $$\mu(1 - \varphi_1) = c \implies \boxed{\mu = \frac{c}{1 - \varphi_1}}$$

En pratique, on normalise la série pour avoir $c = 0 \implies \mu = 0$. Cela simplifie toutes les dérivations suivantes.

② Calcul de la variance

La stationnarité impose $\text{Var}[X_t] = \text{Var}[X_{t-1}] = \sigma^2$. On calcule la variance des deux membres (avec $c = 0$) :

Dérivation — Variance d'un AR(1)
$$\sigma^2 = \text{Var}[\varphi_1 X_{t-1} + \varepsilon_t] = \varphi_1^2 \underbrace{\text{Var}[X_{t-1}]}_{\sigma^2} + \underbrace{\text{Var}[\varepsilon_t]}_{\sigma_\varepsilon^2}$$ $$\sigma^2(1 - \varphi_1^2) = \sigma_\varepsilon^2 \implies \boxed{\sigma^2 = \frac{\sigma_\varepsilon^2}{1 - \varphi_1^2}}$$ $$\text{Condition : } \varphi_1^2 < 1 \iff |\varphi_1| < 1$$
Condition de stationnarité d'un AR(1)
La variance est positive si et seulement si $|\varphi_1| < 1$. Cela donne la condition nécessaire et suffisante de stationnarité d'un AR(1). Si $\varphi_1 = 1$, on a une marche aléatoire (*random walk*) — non-stationnaire (variance infinie). Si $|\varphi_1| > 1$, le processus est explosif.

③ Calcul de l'autocorrélation

C'est le résultat le plus élégant : le paramètre $\varphi_1$ d'un AR(1) est exactement l'autocorrélation au lag 1.

Dérivation — Autocorrélation AR(1)
$$\gamma_1 = \text{Cov}(X_t, X_{t+1}) = \mathbb{E}[X_t \cdot X_{t+1}] \quad (\mu = 0)$$ $$= \mathbb{E}[X_t(\varphi_1 X_t + \varepsilon_{t+1})] = \varphi_1 \underbrace{\mathbb{E}[X_t^2]}_{\text{Var}[X_t]} + \underbrace{\mathbb{E}[X_t \varepsilon_{t+1}]}_{= 0 \text{ (indép.)}}$$ $$\gamma_1 = \varphi_1 \sigma^2 \implies \rho_1 = \frac{\gamma_1}{\sigma^2} = \varphi_1$$ $$\boxed{\varphi_1 = \rho_1 = \text{ACF}(1)}$$

Et plus généralement, l'ACF d'un AR(1) décroît géométriquement : $\rho_\tau = \varphi_1^\tau$. C'est pourquoi l'ACF d'un AR(1) décroît exponentiellement vers zéro.

07

Sélection du modèle — AIC & BIC

Pour les ordres $p > 1$, les coefficients doivent être estimés numériquement (maximum de vraisemblance). La question devient : quel ordre $p$ choisir ? Ajouter plus de paramètres améliore toujours le fit en échantillon, mais au risque du surapprentissage.

AIC — Akaike Information Criterionpénalisation légère
$$\text{AIC} = 2p - 2\ln(\hat{L})$$
p

Nombre de paramètres du modèle

$\hat{L}$

Valeur maximale de la vraisemblance (*likelihood*)

Interprétation

Minimiser l'AIC. La pénalité $2p$ est constante par paramètre.

Biais

Tend à sur-sélectionner (choisir des modèles trop complexes)

BIC — Bayesian Information Criterionpénalisation forte
$$\text{BIC} = \ln(n) \cdot p - 2\ln(\hat{L})$$
n

Nombre d'observations

$\ln(n) \cdot p$

Pénalité croissante avec $n$ et $p$

Interprétation

Minimiser le BIC. Pénalise plus sévèrement les grands modèles.

Avantage

Plus parcimonieux que l'AIC, cohérent pour $n \to \infty$

Exemple concret — S&P 500 (cours, slide 51)
Sur les rendements S&P 500 (2023–2024), l'ACF montre très peu d'autocorrélation. L'AIC continue de diminuer avec l'ordre $p$ tandis que le BIC recommande un modèle d'ordre 3 (ou même 1). En pratique, lorsque AIC et BIC divergent, le BIC est préféré pour les données financières courtes.

Formules clés pour l'examen

ACF d'un AR(1)résultat analytique
$$\rho_\tau = \varphi_1^\tau$$
Signification

L'autocorrélation au lag τ décroît géométriquement avec le lag.

Conséquence

Pour $|\varphi_1| < 1$, l'ACF tend vers 0 — la série « oublie » son passé.

Exemple numérique

$\varphi_1 = 0.7$ : $\rho_1 = 0.7$, $\rho_2 = 0.49$, $\rho_3 = 0.34$, …

Cas $\varphi_1 < 0$

Alternance : $\rho_1 < 0$, $\rho_2 > 0$, $\rho_3 < 0$, … (oscillations)

Variance d'un AR(1)condition de stationnarité
$$\sigma^2_{X} = \frac{\sigma^2_\varepsilon}{1 - \varphi_1^2}$$
$\sigma^2_\varepsilon$

Variance du bruit blanc (innovation)

$1 - \varphi_1^2$

Facteur d'amplification : plus $|\varphi_1| \to 1$, plus la variance explose

Exemple numérique

$\varphi_1 = 0.9$, $\sigma_\varepsilon = 1$ → $\sigma^2_X = 1/(1-0.81) \approx 5.26$

Intuition

La corrélation temporelle "accumule" la variance — la série est plus volatile que le bruit seul.

Moyenne d'un AR(1)long terme
$$\mu = \frac{c}{1 - \varphi_1}$$
c

Constante (intercept) du modèle AR(1)

Intuition

Le dénominateur $(1-\varphi_1)$ agit comme un diviseur qui "dilue" la constante selon la mémoire du processus.

Cas normalisé

Si $c=0 \Rightarrow \mu = 0$ : on travaille avec des données centrées.

Exemple numérique

$c = 0.1$, $\varphi_1 = 0.8$ → $\mu = 0.1/0.2 = 0.5$

Stationnarité faibleprérequis
$$\mathbb{E}[X_t] = \mu = \text{cst} \quad \text{et} \quad \text{Cov}(X_t, X_{t+\tau}) = \gamma(\tau)$$
Condition (a)

La moyenne ne dépend pas du temps $t$

Condition (b)

L'autocovariance ne dépend que du lag $\tau$, pas de $t$

Test formel

Test ADF : H₀ = non-stationnaire. Rejeter H₀ si p-value < 0.05

Pratique

Les rendements financiers sont quasi-systématiquement stationnaires.

Comment choisir entre AIC et BIC ?
BIC est préféré quand on cherche le "vrai" modèle parcimonieux (consistant asymptotiquement). AIC est préféré quand l'objectif est la prédiction et qu'on tolère un peu plus de complexité. En finance, avec des séries courtes, le BIC est souvent plus adapté.
10

Questions d'examen possibles

● Facile
Qu'est-ce que la stationnarité faible (*weak stationarity*) et pourquoi est-elle nécessaire pour appliquer un modèle AR ?▶

La stationnarité faible requiert deux conditions : (a) la moyenne est constante $\mathbb{E}[X_t] = \mu$ pour tout $t$, et (b) l'autocovariance $\text{Cov}(X_t, X_{t+\tau}) = \gamma(\tau)$ ne dépend que du lag $\tau$, pas du temps absolu $t$. Elle est nécessaire car les modèles AR supposent que les relations entre observations (capturées par les coefficients $\varphi_i$) restent stables dans le temps. Sans stationnarité, les estimateurs sont biaisés, les tests invalides, et le modèle peut capturer des relations qui n'existent pas (*spurious correlations*).

Pourquoi travaille-t-on en général sur les rendements financiers plutôt que sur les prix ?▶

Les prix financiers ne sont pas stationnaires : ils dérivent dans le temps (tendance), ont une variance qui évolue (hétéroscédasticité), et leur test ADF donne quasi-systématiquement une p-value > 0.05. Les rendements $r_t = (X_t - X_{t-1})/X_{t-1}$ ou log-rendements $\ln(X_t/X_{t-1})$ oscillent autour d'une moyenne quasi-nulle avec une variance plus stable. Ils passent le test ADF avec p-value ≈ 0.00. De plus, les rendements ont une interprétation économique directe (performance en %).

Quelle est la différence principale entre un modèle AR(p) et un modèle MA(q) ?▶

Un AR(p) exprime $X_t$ comme combinaison linéaire de ses $p$ valeurs passées : $X_t = c + \sum \varphi_i X_{t-i} + \varepsilon_t$. Un MA(q) l'exprime comme combinaison des $q$ erreurs (chocs) passées : $X_t = \mu + \varepsilon_t + \sum \theta_i \varepsilon_{t-i}$. Conséquence clé : l'ACF d'un MA(q) est nulle pour tous les lags $\tau > q$ (coupure nette), tandis que l'ACF d'un AR(p) décroît progressivement. Un MA(q) est toujours stationnaire, pas un AR(p) si $|\varphi_1| \geq 1$.

● Intermédiaire
Démontrez que la variance d'un AR(1) vaut $\sigma^2_X = \sigma^2_\varepsilon / (1 - \varphi_1^2)$ et déduisez la condition de stationnarité.▶

Avec $c = 0$ et $X_t = \varphi_1 X_{t-1} + \varepsilon_t$ :

$\text{Var}[X_t] = \text{Var}[\varphi_1 X_{t-1} + \varepsilon_t] = \varphi_1^2 \text{Var}[X_{t-1}] + \text{Var}[\varepsilon_t]$ (par indépendance de $\varepsilon_t$ et $X_{t-1}$)

Si le processus est stationnaire : $\text{Var}[X_t] = \text{Var}[X_{t-1}] = \sigma^2$, donc :

$\sigma^2 = \varphi_1^2 \sigma^2 + \sigma^2_\varepsilon \Rightarrow \sigma^2(1 - \varphi_1^2) = \sigma^2_\varepsilon \Rightarrow \sigma^2 = \frac{\sigma^2_\varepsilon}{1-\varphi_1^2}$

Pour que cette variance soit positive et finie, il faut $1 - \varphi_1^2 > 0$, soit $|\varphi_1| < 1$. C'est la condition nécessaire et suffisante de stationnarité de l'AR(1).

Comment l'ACF permet-elle d'identifier si une série a un comportement "tendanciel" ou "mean-reverting" ?▶

L'ACF mesure $\rho_\tau = \text{Cor}(X_t, X_{t+\tau})$. Pour un AR(1), $\rho_\tau = \varphi_1^\tau$.

Si $\varphi_1 > 0$ (tendanciel) : toutes les barres ACF sont positives et décroissent lentement. Cela signifie que des valeurs élevées aujourd'hui sont corrélées avec des valeurs élevées demain — la série a de l'inertie, une tendance. L'ACF reste au-dessus de zéro pour de nombreux lags.

Si $\varphi_1 < 0$ (mean-reverting) : les barres alternent, avec $\rho_1 < 0$ significatif. Cela signifie qu'une valeur élevée aujourd'hui prédit une valeur basse demain — la série oscille autour de sa moyenne. Exemple : les rendements du VIX montrent des autocorrélations négatives significatives au lag 1.

Si les barres ACF sont toutes dans l'intervalle de confiance : la série est proche d'un bruit blanc, difficile à prédire.

Qu'est-ce que la stationnarité stricte et en quoi diffère-t-elle de la stationnarité faible ?▶

La stationnarité stricte impose que la distribution jointe complète $F(X_{t_1+\tau}, \ldots, X_{t_n+\tau}) = F(X_{t_1}, \ldots, X_{t_n})$ soit invariante par translation temporelle — pour tous les $n$, tous les $\tau$. C'est une condition très forte qui porte sur tous les moments de toutes les distributions marginales et jointes.

La stationnarité faible n'impose que deux conditions : (a) moyenne constante et (b) autocovariance ne dépendant que du lag. Elle ne porte que sur les deux premiers moments.

Relations : stationnarité stricte $\Rightarrow$ stationnarité faible (si les variances existent). L'inverse n'est pas vrai en général. Exception : pour les processus gaussiens, les deux notions sont équivalentes (car un gaussien est entièrement caractérisé par ses deux premiers moments). En pratique, on utilise toujours la stationnarité faible, plus vérifiable.

● Difficile
Montrez que pour un AR(1), le coefficient $\varphi_1$ est exactement égal à la corrélation entre $X_t$ et $X_{t+1}$. Qu'est-ce que cela implique pour l'estimation ?▶

Avec $\mu = 0$, on calcule $\gamma_1 = \text{Cov}(X_t, X_{t+1}) = \mathbb{E}[X_t \cdot X_{t+1}]$.

$\gamma_1 = \mathbb{E}[X_t(\varphi_1 X_t + \varepsilon_{t+1})] = \varphi_1 \mathbb{E}[X_t^2] + \mathbb{E}[X_t \varepsilon_{t+1}]$

Comme $\varepsilon_{t+1}$ est indépendant de $X_t$ : $\mathbb{E}[X_t \varepsilon_{t+1}] = \mathbb{E}[X_t]\mathbb{E}[\varepsilon_{t+1}] = 0$.

Donc $\gamma_1 = \varphi_1 \sigma^2$, et $\rho_1 = \gamma_1 / \sigma^2 = \varphi_1$. CQFD.

Implication pour l'estimation : le coefficient $\varphi_1$ d'un AR(1) peut être estimé directement comme la corrélation empirique entre $X_t$ et $X_{t-1}$ (estimateur de Pearson), sans avoir recours à un algorithme d'optimisation numérique. C'est un résultat unique à l'AR(1) — pour les ordres supérieurs, l'estimation analytique n'est plus possible.

Pourquoi l'AIC tend-il à sur-sélectionner (choisir trop de paramètres) par rapport au BIC ?▶

Comparons les pénalités : AIC pénalise avec $2p$, BIC avec $\ln(n) \cdot p$.

Pour qu'AIC soit plus sévère que BIC, il faudrait $2 > \ln(n)$, soit $n < e^2 \approx 7.4$. Pour tout $n \geq 8$, $\ln(n) > 2$, donc BIC pénalise toujours plus que AIC l'ajout d'un paramètre. Plus $n$ est grand, plus l'écart est important (BIC pénalise avec $\ln(n) \approx 5$ pour $n=150$, $\approx 7.6$ pour $n=2000$).

Conséquence : face à deux modèles qui s'ajustent aussi bien, AIC préfèrera le plus complexe (plus de paramètres), tandis que BIC restera sur le modèle parcimonieux. En termes théoriques, BIC est consistent (converge vers le vrai ordre si $n \to \infty$) tandis qu'AIC ne l'est pas. C'est pourquoi BIC est préféré pour l'identification de structure.

Comment étendrait-on le cadre AR aux séries non-stationnaires ? Expliquez le modèle ARIMA.▶

Un modèle ARIMA(p, d, q) (*Autoregressive Integrated Moving Average*) étend ARMA aux séries non-stationnaires via un paramètre $d$ d'intégration. L'idée : si une série $X_t$ est non-stationnaire mais que sa différence $d$-ième $\Delta^d X_t$ est stationnaire, on applique un ARMA(p,q) à la série différenciée.

Pour $d = 1$ (le cas le plus courant) : $\Delta X_t = X_t - X_{t-1}$ est stationnaire. On modélise $Y_t = \Delta X_t$ avec un ARMA(p,q). Exemple : les prix d'actions nécessitent souvent ARIMA(p,1,q) car leur différence première (= les rendements) est stationnaire.

La marche aléatoire $X_t = X_{t-1} + \varepsilon_t$ est un cas particulier ARIMA(0,1,0). Les extensions SARIMA ajoutent une composante saisonnière.

Pièges classiques

⚠
Appliquer un modèle AR directement sur les prix — Les prix ne sont pas stationnaires. Il faut toujours stationnariser (rendements, différences) avant toute modélisation. Vérifier avec le test ADF.
⚠
Confondre "bon fit" et "bonne prédiction" — Un modèle peut avoir un excellent $R^2$ in-sample mais de mauvaises prédictions hors-échantillon. Dans le cours, l'AR(1) sur $X_t = X_{t-1} + \varepsilon$ donne coeff ≈ 1 et fit parfait en-échantillon, mais les prédictions divergent rapidement hors-échantillon.
⚠
Oublier la condition $|\varphi_1| < 1$ pour la stationnarité — Si $|\varphi_1| \geq 1$, le modèle AR(1) n'est pas stationnaire. La variance explose. Cette condition n'est pas automatiquement vérifiée lors de l'estimation.
⚠
Confondre ACF et PACF — L'ACF mesure la corrélation totale entre $X_t$ et $X_{t+\tau}$ (y compris les effets indirects). La PACF (*Partial ACF*) mesure la corrélation directe après élimination des lags intermédiaires. Pour identifier l'ordre d'un AR, on utilise la PACF (coupure nette à $p$). Pour identifier l'ordre d'un MA, on utilise l'ACF.
⚠
Ignorer la définition du lag temporel — La fréquence importe ! Un lag τ=1 signifie des choses très différentes selon que les données sont journalières, hebdomadaires ou mensuelles. Dans le cours : "when does a day start?" — la définition exacte de la fréquence d'échantillonnage est non triviale.
⚠
Croire que AIC toujours < BIC — Comparer AIC et BIC uniquement pour le même modèle n'a pas de sens. On compare les valeurs AIC entre eux et BIC entre eux. On ne compare jamais AIC d'un modèle avec BIC d'un autre.
⚠
Négliger l'hétéroscédasticité — Les modèles AR supposent une variance du bruit $\sigma_\varepsilon^2$ constante. En finance, la volatilité est souvent variable (hétéroscédasticité). Pour modéliser cela correctement, il faut des modèles GARCH — une extension naturelle au-delà de ce cours.

Fiche de révision finale

Concepts Fondamentaux

  • Time Series : $\{X_{t_i}\}$ ordonnée dans le temps
  • Lag τ : décalage temporel entre observations
  • Stationnarité faible : μ=cst + Cov dépend de τ seul
  • Stationnarité stricte : distribution invariante par translation
  • Test ADF : p-value < 0.05 → stationnaire ✓
  • En pratique : travailler sur les rendements

ACF — Autocorrelation Function

  • Formule : $\rho_\tau = \text{Cov}(X_t, X_{t+\tau}) / \sigma^2$
  • Confiance : $\pm 1.96/\sqrt{n}$ (95%)
  • ACF > 0 décroissant → tendance (φ > 0)
  • ACF alternant ± → mean-reverting (φ < 0)
  • ACF ≈ 0 partout → bruit blanc, pas de structure
  • AR(1) : ACF(τ) = φ₁τ (décroissance géom.)

Famille AR / MA / ARMA

  • AR(p) : $X_t = c + \sum \varphi_i X_{t-i} + \varepsilon_t$
  • MA(q) : $X_t = \mu + \varepsilon_t + \sum \theta_i \varepsilon_{t-i}$
  • ARMA(p,q) : valeurs + erreurs passées
  • Sélection : minimiser AIC ou BIC
  • AIC : $2p - 2\ln L$ (légère pénalité)
  • BIC : $\ln(n)p - 2\ln L$ (forte pénalité)

AR(1) — Résultats Clés

  • Modèle : $X_t = c + \varphi_1 X_{t-1} + \varepsilon_t$
  • Moyenne : $\mu = c / (1 - \varphi_1)$
  • Variance : $\sigma^2 = \sigma^2_\varepsilon / (1 - \varphi_1^2)$
  • Autocorrélation : $\varphi_1 = \rho_1 = \text{ACF}(1)$
  • Stationnarité : $|\varphi_1| < 1$ requis !
  • φ₁ > 0 → tendance ; φ₁ < 0 → mean-reverting
Workflow complet — À retenir
① Données brutes (non-stationnaires en général) → ② Stationnariser (rendements / log / diff) → ③ Vérifier ADF (p-value < 0.05) → ④ Calculer ACF (identifier la structure) → ⑤ Choisir le modèle AR/MA/ARMA et l'ordre → ⑥ Estimer les paramètres → ⑦ Valider avec AIC/BIC et tests résiduels
Exemples du cours à citer en oral
EUR/USD 2012 : prix non-stationnaire (ADF p=0.15) → rendements stationnaires (p=0.00), φ₁≈-0.125, faible structure.
VIX 2010-2013 : autocorrélations négatives significatives au lag 1 (mean-reverting).
S&P 500 2023-24 : AR(3) retenu par BIC sur les rendements.
PIB Suisse : AR de plus haut ordre nécessaire pour capturer la structure trimestrielle.
