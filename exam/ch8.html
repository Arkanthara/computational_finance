Agent Based Models

Des règles locales simples, des comportements globaux complexes. Modéliser les marchés financiers du bas vers le haut.

Bottom-Up Minority Game Cont-Bouchaud Lux-Marchesi Phase Transition Fat Tails Herding
🍺 Mise en contexte — L'histoire du bar El Farol

Un économiste, un physicien et un informaticien décident d'aller au bar El Farol un jeudi soir. L'économiste : "Avec des agents parfaitement rationnels, la fréquentation converge vers l'équilibre de Nash à exactement 60%." Le physicien : "Les clusters stochastiques génèrent des queues de distribution en loi de puissance." L'informaticien tape frénétiquement : "Ma simulation de 1000 agents dit 85% — restez chez vous."

Résultat : ils restent tous les trois chez eux. Le bar est vide à 0%. Personne n'est content. 🙈
Morale : si tout le monde prédit la même chose avec la même méthode, la prédiction se détruit elle-même. C'est le problème d'El Farol — et la raison d'être des Agent Based Models.

01

Résumé exécutif (30 secondes)

Définition en une phrase

Les Agent Based Models (ABM) sont des modèles bottom-up simulant les interactions de $N$ agents aux règles locales simples pour faire émerger des comportements macroéconomiques complexes — notamment les fat tails, le herding et la volatilité agrégée — que les modèles top-down ne parviennent pas à reproduire naturellement.

Paradigme

Bottom-Up

Règles locales + interactions entre agents → comportement global émergent. L'inverse du top-down (équations différentielles macroéconomiques).

3 Modèles du cours

Cont-Bouchaud · Lux-Marchesi · Minority Game

Chacun capture un mécanisme différent : herding par clusters, hétérogénéité fundamentalists/chartists, compétition stratégique.

Résultats reproduits

Stylized Facts

Fat tails des rendements, volatility clustering, non-gaussianité — des faits empiriques impossibles à obtenir avec la distribution normale.

Résultat clé (MG)

Transition de Phase à $\alpha_c$

Le Minority Game exhibe une transition de phase à $\alpha_c \approx 0.34$ (pour $S=2$), séparant régime symétrique (herding) et asymétrique (aléatoire).

02

Réponse modèle d'oral (3–5 min)

Les Agent Based Models représentent une approche bottom-up de la modélisation financière. Plutôt que de partir d'équations macroéconomiques — comme dans les modèles Black-Scholes ou GARCH — on définit des règles locales simples pour chaque agent individuel, et le comportement global émerge de leurs interactions. L'intuition fondamentale est que les marchés sont le résultat d'interactions entre des participants hétérogènes avec des stratégies et des biais différents.

Trois modèles illustrent cette approche. Le modèle de Cont-Bouchaud se concentre sur le comportement grégaire : des agents forment des clusters aléatoires qui agissent ensemble. Quand le paramètre d'activité $a$ est faible, les grands clusters dominent et produisent des fat-tailed distributions de rendements — un fait stylisé majeur des marchés réels qu'une gaussienne ne peut reproduire.

Le modèle de Lux-Marchesi distingue deux classes d'agents : les fundamentalists, qui ancrent le prix à la valeur fondamentale, et les chartists — optimistes et pessimistes — qui suivent ou s'opposent à la tendance. Leurs interactions dynamiques, notamment la possibilité de changer de catégorie, reproduisent les distributions de rendements empiriques et remettent explicitement en question l'hypothèse d'efficience des marchés.

Le Minority Game, proposé par Challet et Zhang, est le plus analytiquement riche. $N$ agents — en nombre impair — choisissent entre deux actions à chaque tour. Ceux qui sont dans la minorité gagnent. Chaque agent dispose de $S$ stratégies, chacune étant une table de correspondance entre un historique de $M$ bits et une action. La sélection se fait via une loi de Boltzmann sur les scores accumulés.

Le paramètre clé est $\alpha = 2^M/N$ — le rapport entre la taille de l'espace des stratégies et le nombre d'agents. On observe une transition de phase à $\alpha_c \approx 0.34$ : en-dessous, les agents sont trop nombreux pour l'espace de stratégies disponible, provoquant du herding et une variance $\sigma^2 > N$ (pire que le hasard). Au-dessus, trop peu d'agents se retrouvent dans chaque stratégie et le comportement devient aléatoire. Au voisinage de $\alpha_c$, la variance est minimale — les agents se coordonnent spontanément vers une allocation collective optimale, sans communication explicite. Ce phénomène émergent est l'insight profond du modèle.

Enfin, le lien avec les marchés réels s'établit via $r(t) = A(t)/\gamma$, où l'attendance $A$ joue le rôle de l'excès de pression d'achat ou de vente. Les extensions du Minority Game permettent de reproduire des distributions de rendements proches des données empiriques.

1 · Modèle Cont-Bouchaud

Idée centrale

Le comportement grégaire (herding) des investisseurs, modélisé par des clusters aléatoires, suffit à expliquer les queues épaisses des distributions de rendements. Un mécanisme minimaliste pour un résultat macroéconomique puissant.

Mécanisme

Des agents se regroupent en clusters aléatoires par un processus de percolation. Chaque cluster décide indépendamment :

  • Vendre avec probabilité $a$
  • Acheter avec probabilité $a$
  • Ne rien faire avec probabilité $1 - 2a$, avec la contrainte $a \leq 0.5$

$a = 0.5$ : tous les clusters agissent → forces équilibrées → distribution gaussienne des rendements. $a \ll 0.5$ : peu de clusters actifs, mais les grands clusters dominent les petits → distribution à queues épaisses, car la taille des clusters suit une loi de puissance.

Extension possible

Le modèle peut être enrichi, par exemple en ajoutant une taxe Tobin (taxe sur les transactions financières). Les ABM sont des briques modulaires.

2 · Modèle Lux-Marchesi

Idée centrale

La coexistence de types de traders hétérogènes — fundamentalists et chartists — et leur capacité à changer de type reproduisent les distributions de rendements empiriques à différentes échelles de temps $\tau$.

Trois types d'agents

  • Fundamentalists : comparent le prix $P$ à la "vraie" valeur $P^*$. Si $P < P^*$ → achètent ; si $P > P^*$ → vendent. Force de rappel vers la valeur fondamentale.
  • Chartists Optimistes : suivent la tendance (momentum traders). Achètent quand les prix montent.
  • Chartists Pessimistes : contre-tendance (contrarians). Vendent quand les prix montent.

Les agents peuvent changer de catégorie selon la profitabilité récente de chaque type. Cela crée des cycles endogènes : bulles dominées par les chartists, corrections tirées par les fundamentalists.

Non-EMH explicite

La diversité des participants produit des fat tails pour $\tau$ petit (jours) qui s'estompent pour $\tau$ grand (mois) — cohérent avec les données empiriques et incompatible avec l'EMH dans sa version forte.

3 · Minority Game — Définitions formelles

Problème d'El Farol (Brian Arthur, 1994)

$N$ personnes vont au bar El Farol si et seulement si la fréquentation prévue est < 60%. Problème : il n'existe pas de stratégie déterministe stable — si tout le monde prédit "le bar sera vide", ils y vont tous, le bar est bondé, et la prédiction se détruit. Le MG formalise ce problème de coordination.

Structure du modèle

  • $N$ agents (impair, pour garantir toujours une minorité stricte)
  • Historique $\mu(t)$ de $M$ bits : encode les $M$ derniers outcomes
  • $S$ stratégies par agent : chacune est un vecteur de $2^M$ bits (réponse pour chaque histoire)
  • $2^{2^M}$ stratégies possibles au total — croissance hyper-exponentielle
Explosion de l'espace des stratégies

$M=2 \to 16$ · $M=3 \to 256$ · $M=4 \to 65{,}536$ · $M=5 \to 4.3 \times 10^9$ stratégies
Solution algorithmique : on ne stocke pas les indices — on tire aléatoirement un vecteur de $2^M$ bits pour chaque stratégie de chaque agent.

Sélection de stratégie (Boltzmann)

Softmax / Boltzmann strategy selection
$$P(s_j^t) = \frac{e^{\lambda U_{s_j}(t)}}{\sum_{k=1}^{S} e^{\lambda U_{s_k}(t)}}, \quad 1 \leq j \leq S, \quad \lambda > 0$$

Quand $\lambda \to \infty$ : l'agent choisit toujours la stratégie de score maximal (cas standard). Quand $\lambda \to 0$ : choix uniforme aléatoire.

Attendance et utilité

$$A(t) = \sum_{i=1}^{N} a_i^{\mu(t)}(t), \quad a_i \in \{-1, +1\}$$
Utility update — virtual scoring
$$U_{i,s}(t+1) = U_{i,s}(t) - a_{i,s}^{\mu(t)} \cdot \frac{A(t)}{\beta}$$

Intuition : si l'action $a_{i,s}$ a le même signe que $A(t)$ → stratégie dans la majorité → score diminue. Signe opposé → stratégie gagnante (minorité) → score augmente. Toutes les stratégies sont mises à jour (virtual scoring), même celles non jouées.

Paramètre de contrôle et prévisibilité

$$\alpha = \frac{P}{N} = \frac{2^M}{N} \qquad H = \frac{1}{P}\sum_{\mu=0}^{2^M-1} \langle A|\mu \rangle^2$$

$\alpha$ mesure la densité d'agents dans l'espace de stratégies. $H$ mesure l'exploitabilité des patterns : $H \approx 0$ → marché imprévisible ; $H > 0$ → opportunités d'arbitrage.

Les deux phases

  • Phase symétrique ($\alpha < \alpha_c$) : $H \approx 0$, $\sigma^2/N > 1$ — herding, pire que le hasard
  • Phase asymétrique ($\alpha > \alpha_c$) : $H > 0$, $\sigma^2/N \to 1$ — comportement quasi-aléatoire
  • Point critique $\alpha_c \approx 0.3374$ (pour $S=2$) : $\sigma^2/N$ minimal — coordination collective optimale

Diagrammes & Schémas

① Top-Down vs Bottom-Up

Les ABM laissent les stylized facts émerger naturellement, sans les postuler dans les équations.

② El Farol Bar — Dynamique de l'attendance

Les fluctuations de l'attendance autour de 60% mesurent le bonheur collectif. Réduire σ² = mieux coordonner les agents.

③ Cont-Bouchaud — Gaussienne vs Queue Épaisse

Quand $a \ll 0.5$, la taille des clusters actifs suit une loi de puissance → queues épaisses des rendements — fait stylisé clé des marchés réels.

④ Lux-Marchesi — Interactions des types d'agents

Les agents peuvent changer de type selon la profitabilité. Cette dynamique crée des cycles endogènes : bulles (chartists dominent) → corrections (fundamentalists corrigent).

⑤ Minority Game — Espace des stratégies (M=2, 16 stratégies)

Algorithme : on tire un vecteur de $2^M$ bits aléatoires pour chaque stratégie. Pour $M=5$, cela évite de stocker $2^{32} \approx 4\times10^9$ stratégies.

⑥ Transition de Phase — σ²/N vs α (S=2)

Master curve (S=2) : la courbe ne dépend que de α, pas séparément de M et N. Cette universalité est une prédiction testable et vérifiée numériquement.

⑦ Algorithme du Minority Game

Complexité : $O(T \cdot N \cdot S \cdot 2^M)$ par simulation. Pour grands M, il faut compresser les stratégies en bitsets.

⑧ Du Minority Game aux marchés financiers

La chaîne Minority Game → marchés financiers. L'attendance joue le rôle du market order imbalance dans les modèles de microstructure.
05

Formules importantes

Sélection de stratégie — BoltzmannCore MG
$$P(s_j^t) = \frac{e^{\lambda U_{s_j}(t)}}{\displaystyle\sum_{k=1}^{S} e^{\lambda U_{s_k}(t)}}, \quad 1 \leq j \leq S, \quad \lambda > 0$$
Variables

$U_{s_j}(t)$ : score de la stratégie $s_j$ · $\lambda$ : rationalité · $S$ : nombre de stratégies par agent

Cas limites

$\lambda \to \infty$ : greedy (toujours la meilleure). $\lambda \to 0$ : choix uniforme. MG standard : $\lambda \to \infty$.

Intuition

Distribution de Boltzmann (physique stat). La probabilité de choisir une stratégie est exponentiellement plus grande pour les scores élevés.

Lien finance

Analogue à un investisseur qui sur-pondère la stratégie ayant la meilleure performance récente (momentum biais).

Mise à jour de l'utilitéVirtual Scoring
$$U_{i,s}(t+1) = U_{i,s}(t) - a_{i,s}^{\mu(t)} \cdot \frac{A(t)}{\beta}$$
Variables

$a_{i,s}^{\mu(t)} \in \{-1,+1\}$ : action de la stratégie $s$ pour l'histoire $\mu$ · $\beta \in \{1, N, 2^M\}$ : normalisation

Intuition

Même signe $a$ et $A$ → majorité → $U$ diminue. Signes opposés → minorité gagnante → $U$ augmente.

Virtual scoring

Toutes les stratégies de chaque agent sont mises à jour, même celles non jouées. Apprentissage contrafactuel efficace.

Choix de β

$\beta=1$ : brut · $\beta=N$ : normalise par agents · $\beta=2^M$ : normalise par taille de l'espace

Paramètre de contrôle αPhase Transition
$$\alpha = \frac{P}{N} = \frac{2^M}{N} \qquad \alpha_c \approx 0.3374 \text{ (S=2)} \qquad \alpha_c(S) \approx \alpha_{c,S=2} + \frac{S-2}{2}$$
Interprétation

Ratio : taille espace de stratégies / nombre d'agents. Mesure la "densité" d'agents dans l'espace $\{0,1\}^{2^M}$.

Régimes

$\alpha < \alpha_c$ : herding (trop d'agents / stratégies). $\alpha > \alpha_c$ : aléatoire. $\alpha \approx \alpha_c$ : optimum.

Universalité

La courbe $\sigma^2/N$ vs $\alpha$ est une master curve — elle ne dépend pas de $N$ et $M$ séparément mais uniquement de leur ratio $\alpha$.

Analogie physique

Analogue au nombre de Reynolds (turbulence) ou au champ critique en magnétisme (transition ferromagnétique ↔ paramagnétique).

Prévisibilité HInformation & EMH
$$H = \frac{1}{P}\sum_{\mu=0}^{2^M-1} \langle A|\mu \rangle^2, \quad P = 2^M$$
Variables

$\langle A|\mu \rangle$ : moyenne temporelle de $A(t)$ conditionnel à l'historique $\mu$ · $P = 2^M$ histoires

Intuition

Si certaines histoires $\mu$ prédisent systématiquement un excès d'acheteurs → $\langle A|\mu \rangle \neq 0$ → marché exploitable.

Lien EMH

$H = 0$ → marché efficient (patterns aléatoires). $H > 0$ → patterns exploitables par un agent rationnel externe.

Phases

Symétrique : $H \approx 0$. Asymétrique : $H > 0$ et croissant. La phase symétrique est paradoxalement plus "inefficiente" (herding) mais aussi plus "imprévisible".

Variance de l'attendance σ²Volatilité
$$\sigma^2 = \text{Var}(A) = \frac{1}{T}\sum_{t=0}^{T} A(t)^2 \qquad \text{Référence aléatoire : } \sigma^2_{ref} = N$$
Dérivation

Si agents indépendants : $\text{Var}(a_i)=1$, $\text{Cov}(a_i,a_j)=0$ → $\text{Var}(A)=N$. Corr. négatives → $\sigma^2 < N$.

Interprétation

$\sigma^2/N < 1$ : coordination efficace (anti-corrélations). $\sigma^2/N > 1$ : herding (corrélations positives).

Finance

$\sigma^2$ est l'analogue de la variance des rendements. Zone optimale $\sigma^2 \ll N$ = marché bien coordonné = faible volatilité.

Minimum

$\sigma^2/N \approx 0.28$ au minimum (S=2) → réduit de 72% par rapport au hasard ! Émergence spontanée de l'anti-coordination.

Prix et rendements financiersMarket Mapping
$$P(t) = P(t-1)\cdot\exp\!\left(\frac{A(t)}{\gamma}\right) \quad \Rightarrow \quad r(t) = \ln\frac{P(t)}{P(t-1)} = \frac{A(t)}{\gamma}$$
Variables

$\gamma$ : paramètre de liquidité, typiquement multiple de $N$. $A(t) > 0$ → excès acheteurs → prix monte.

Intuition

L'imbalance d'ordres (order flow imbalance) génère le mouvement de prix. Conforme aux modèles de microstructure de marché.

Extensions

Agents contrarians, inaction possible (refus de jouer), autocorrélation → distributions de rendements plus réalistes avec fat tails.

Résultat

La distribution de $r(t) \propto A(t)$ hérite des propriétés du MG. Phase sym. avec herding → $|A|$ souvent grand → fat tails des rendements.

08

Perspective historique

~1960–1985
Dominance de l'EMH et des modèles gaussiens
Fama (1970) : l'Efficient Market Hypothesis domine. Agents représentatifs rationnels, prix suivent une marche aléatoire, rendements gaussiens. Black-Scholes (1973) devient le standard. Le top-down règne sans partage.
1987
Black Monday — La fin de l'innocence gaussienne
Le Dow Jones perd 22% en une journée. Un modèle gaussien prédirait cet événement avec une probabilité de l'ordre de $10^{-160}$ — un choc "impossible" sous l'hypothèse normale. Les fat tails deviennent incontournables.
1994
El Farol Bar Problem — Brian Arthur (Santa Fe Institute)
Premier modèle formel montrant qu'il n'existe pas de stratégie déterministe stable dans un jeu de coordination de ce type. Pose les fondations conceptuelles du Minority Game.
1997
Minority Game — Challet & Zhang (Université de Fribourg)
Article fondateur. Formalisation avec $N$ agents, $M$ bits d'historique, $S$ stratégies. Découverte numérique de la transition de phase à $\alpha_c$. Point de départ d'une centaine d'articles de suivi.
1999
Cont-Bouchaud (percolation) & Lux-Marchesi (hétérogénéité)
R. Cont et J.-P. Bouchaud (Capital Fund Management) : modèle de percolation pour les queues épaisses. T. Lux et M. Marchesi : fundamentalists + chartists avec switching. Deux approches différentes, même résultat : fat tails.
2001–2005
Théorie analytique du Minority Game (Spin Glass)
Application des méthodes de la physique des verres de spin (replica method, mean field theory) au MG. Résultats analytiques exacts pour $\alpha_c$, $\sigma^2$ et $H$. Connexion profonde entre finance et physique statistique.
Aujourd'hui
ABM en finance systémique et régulation
Les ABM sont utilisés pour le stress testing réglementaire (BCE, BRI), la simulation de marchés à haute fréquence, l'étude de politiques financières (taxe Tobin, circuit breakers) et la modélisation du risque systémique.

Questions d'examen possibles

🟢 Niveau Facile
Qu'est-ce qu'un ABM ? En quoi est-il différent d'une approche top-down ? ▼
Un Agent Based Model (ABM) est un modèle bottom-up : on définit des règles locales simples pour $N$ agents individuels hétérogènes, et le comportement macroéconomique émerge de leurs interactions. Contraire du top-down (ex. Black-Scholes) qui postule directement une dynamique globale via des équations différentielles, souvent en supposant des agents représentatifs homogènes. Les ABM capturent naturellement l'hétérogénéité et les interactions, et reproduisent des stylized facts (fat tails, herding) impossibles à obtenir naturellement dans des modèles gaussiens.
Expliquez le problème d'El Farol et son lien avec le Minority Game. ▼
Arthur (1994) : $N$ personnes décident d'aller au bar El Farol. La soirée est agréable seulement si la fréquentation est <60%. Chacun décide seul, sans connaître la décision des autres. Il n'existe pas de stratégie déterministe stable : si tout le monde prédit "le bar sera vide → j'y vais", le bar est bondé, et la prédiction se détruit elle-même (self-defeating prophecy). Le Minority Game formalise ce problème : $N$ agents (impair) choisissent entre deux actions ; ceux dans la minorité gagnent. L'objectif global est de minimiser la variance de l'attendance, i.e. de s'approcher d'une répartition 50/50 avec le moins de fluctuations possible.
Quel est l'effet du paramètre 'a' dans le modèle Cont-Bouchaud ? ▼
$a$ est la probabilité qu'un cluster décide d'acheter (ou de vendre), avec $a \leq 0.5$. $a = 0.5$ : tous les clusters sont actifs, les forces s'équilibrent → distribution gaussienne des rendements. $a \ll 0.5$ : peu de clusters actifs, mais les grands clusters, qui suivent une loi de puissance, exercent des forces asymétriques → fat-tailed distribution des rendements. Intuition : le comportement grégaire (herding) amplifie les fluctuations extrêmes, reproduisant ce qu'on observe sur les vrais marchés.
🔵 Niveau Intermédiaire
Définissez α et expliquez la transition de phase du Minority Game. ▼
$\alpha = 2^M/N$ est le ratio entre la taille de l'espace de stratégies ($P = 2^M$) et le nombre d'agents $N$. C'est LE paramètre de contrôle.
Phase symétrique ($\alpha < \alpha_c \approx 0.34$ pour $S=2$) : trop d'agents pour peu de stratégies disponibles → compétition intense → herding → $\sigma^2/N > 1$ (pire que le hasard). La prévisibilité $H \approx 0$.
Phase asymétrique ($\alpha > \alpha_c$) : peu d'agents par stratégie → comportement essentiellement aléatoire → $\sigma^2/N \to 1$, $H > 0$.
Au point critique $\alpha_c$ : $\sigma^2/N$ est minimisé → les agents se coordonnent spontanément vers une allocation collective optimale, sans communication. La courbe est universelle (master curve) : elle ne dépend pas de $N$ et $M$ séparément mais uniquement de $\alpha$.
Expliquez la règle de mise à jour des scores et le rôle du "virtual scoring". ▼
La règle : $U_{i,s}(t+1) = U_{i,s}(t) - a_{i,s}^{\mu(t)} \cdot A(t)/\beta$. Si $a_{i,s}$ et $A(t)$ ont le même signe → stratégie dans la majorité → score diminue. Signe opposé → stratégie dans la minorité (gagnante) → score augmente.
Virtual scoring : toutes les stratégies de tous les agents sont mises à jour à chaque tour, même celles non jouées. Cela permet d'évaluer contrafactuellement chaque stratégie — "qu'aurais-je obtenu si j'avais joué $s$ ?" — et accélère considérablement la convergence de l'apprentissage. C'est une forme d'apprentissage bayésien implicite.
En quoi le modèle Lux-Marchesi contredit-il l'hypothèse d'efficience des marchés (EMH) ? ▼
L'EMH postule que les prix reflètent instantanément toute l'information disponible et que les rendements sont imprévisibles (marche aléatoire). Le Lux-Marchesi le contredit sur plusieurs points : (1) La présence de chartists crée des tendances et du momentum — des patterns exploitables. (2) La possibilité de changer de catégorie (switching) crée une dynamique non-stationnaire et des régimes différents. (3) Le modèle reproduit des fat tails et du volatility clustering — qui ne devraient pas exister sous l'EMH stricte. (4) La réaction aux nouvelles dépend de la composition courante (fundamentalists vs. chartists dominants) → pas de réponse unique et instantanée. Le modèle est explicitement non-EMH, ce qui est une force : il explique pourquoi les marchés réels ne sont pas efficients.
🔴 Niveau Difficile
Pourquoi σ²/N peut-il être INFÉRIEUR à 1 ? N'est-ce pas paradoxal pour un jeu compétitif ? ▼
Pour des agents indépendants et aléatoires : $\text{Var}(a_i) = 1$, $\text{Cov}(a_i, a_j) = 0$ → $\sigma^2 = N$. Pour obtenir $\sigma^2 < N$, il faut des corrélations négatives entre les actions : $\sum_{i \neq j} \text{Cov}(a_i, a_j) < 0$.
Comment émerge-t-il ? La dynamique du MG crée une pression sélective vers la diversification des stratégies. Si beaucoup d'agents adoptent une stratégie qui prescrit "achète quand $\mu$=01", elle se retrouve souvent dans la majorité → son score chute → les agents abandonnent cette stratégie au profit de son complément (vendre quand $\mu$=01). Ce mécanisme auto-organisateur converge vers des paires de stratégies anti-corrélées, sans aucune coordination explicite. C'est de l'intelligence collective émergente — la "main invisible" dans un cadre de jeu compétitif.
Pourquoi la phase SYMÉTRIQUE a-t-elle H ≈ 0 alors que le herding est intense ? ▼
Question piège classique ! En phase symétrique, le herding crée de grandes fluctuations ($\sigma^2 \gg N$), mais ces fluctuations ne sont pas conditionnées par l'historique $\mu$. $H = \frac{1}{P}\sum_\mu \langle A|\mu\rangle^2 \approx 0$ car, pour chaque histoire $\mu$, les agents sont également divisés entre les deux actions en moyenne : $\langle A|\mu\rangle \approx 0$.
En phase symétrique, la propriété fondamentale est que pour chaque stratégie $s$, son complément $\bar{s}$ est également présent dans la population → symétrie parfaite → $\langle A|\mu\rangle = 0$ pour tout $\mu$. La variance est grande (herding), mais elle est due à des fluctuations aléatoires non prévisibles à partir de $\mu$.
En phase asymétrique, cette symétrie est brisée : certaines stratégies deviennent dominantes pour certains $\mu$ → $\langle A|\mu\rangle \neq 0$ → $H > 0$ → patterns exploitables apparaissent.
Justifiez l'approche algorithmique qui évite de stocker les 2^(2^M) stratégies. ▼
Pour $M=5$, $2^{2^5} = 2^{32} \approx 4.3 \times 10^9$ stratégies — impossible à stocker. Mais il n'est pas nécessaire de les énumérer toutes.
Solution : pour chaque agent $i$, on tire $S$ vecteurs de $2^M$ bits uniformément dans $\{0,1\}^{2^M}$ — chaque vecteur est une stratégie. Cela revient à échantillonner l'espace uniforme sans le parcourir. Chaque agent stocke $S \times 2^M$ bits (ex. : $S=2, M=5$ → $2 \times 32 = 64$ bits par agent, parfaitement gérable).
Validité : la dynamique du MG ne dépend que des stratégies effectivement assignées aux agents, pas de l'ensemble complet. L'échantillonnage aléatoire représente fidèlement la diversité de l'espace. La propriété de symétrie (présence du complément de chaque stratégie avec probabilité $1/2$) est satisfaite en moyenne pour $N$ grand.

Pièges classiques

⚠️
"Phase symétrique" ≠ "actions symétriques". La phase symétrique désigne la symétrie de l'espace de stratégies peuplé (pour chaque stratégie $s$, son complément est présent), pas la symétrie des actions individuelles. En phase symétrique, les agents agissent de façon asymétrique — c'est précisément le herding.
⚠️
σ²/N < 1 ≠ "les agents gagnent plus". Le MG est un zero-sum game : les gains de la minorité sont exactement les pertes de la majorité. σ²/N < 1 mesure l'efficience collective de la coordination — la réduction de la volatilité de l'attendance — pas le profit individuel.
⚠️
αc n'est pas universel. $\alpha_c \approx 0.3374$ est valable pour $S=2$ seulement. Pour $S$ stratégies : $\alpha_c(S) \approx 0.3374 + (S-2)/2$. Pour $S=3$, $\alpha_c \approx 0.84$. Ne jamais citer 0.3374 sans préciser $S=2$.
⚠️
N doit être impair. Sinon, $A(t) = 0$ est possible (égalité parfaite), et la minorité n'est pas définie. $N$ impair garantit $A(t) \neq 0$ à chaque tour — il y a toujours une minorité stricte.
⚠️
Le "virtual scoring" met à jour TOUTES les stratégies. Ce n'est pas une triche — c'est une hypothèse modèle. On suppose que les agents évaluent contrafactuellement toutes leurs stratégies à chaque tour. Certaines variantes du MG n'utilisent que la stratégie effectivement jouée (actual scoring), avec des propriétés différentes.
⚠️
Confondre l'espace total 2^(2^M) et l'espace effectif N×S. Il y a $2^{2^M}$ stratégies possibles, mais seulement $N \times S$ sont effectivement assignées (avec possibles redondances). Pour $N=101, S=2, M=5$ : seulement 202 stratégies sur $4.3 \times 10^9$ possibles — échantillonnage très éparse.
⚠️
Aucun ABM ne reproduit tous les stylized facts. Le cours le souligne explicitement : "Not necessarily all of them with one single model!" Cont-Bouchaud ne reproduit pas le volatility clustering, Lux-Marchesi est difficile à analyser analytiquement, le MG est zero-sum. Ce sont des briques complémentaires, pas des modèles complets.

Fiche de révision finale

Définitions clés

  • ABM : Bottom-up ; règles locales → comportement global émergent
  • Attendance A(t) : Σ aᵢ, imbalance acheteurs/vendeurs
  • Historique μ(t) : M bits des M derniers outcomes
  • Stratégie : vecteur de 2ᴹ bits — réponse pour chaque histoire
  • Virtual scoring : update de toutes les stratégies à chaque tour
  • Prévisibilité H : moyenne de ⟨A|μ⟩² sur toutes les histoires μ
  • αc : point critique de transition de phase

Formules à mémoriser

  • Boltzmann : P(sⱼ) = e^{λUⱼ} / Σe^{λUₖ}
  • Update U : U(t+1) = U(t) − a·A/β
  • Contrôle : α = 2ᴹ/N
  • Prévisibilité : H = (1/P)·Σ⟨A|μ⟩²
  • Var. aléatoire : Var(A) = N (agents indép.)
  • Prix : P(t) = P(t-1)·exp(A/γ)
  • αc(S) : 0.3374 + (S-2)/2

Les 3 modèles ABM

  • Cont-Bouchaud : clusters aléatoires, a≪0.5 → fat tails
  • Lux-Marchesi : fund. + chartists (opt/pess) + switching
  • Minority Game : Challet & Zhang (Fribourg, 1997)
  • N agents (impair), S stratégies, M bits d'historique
  • 2^(2^M) stratégies possibles → tirage aléatoire
  • α = 2ᴹ/N gouverne tout le comportement collectif

Transition de phase (MG, S=2)

  • α < αc : phase sym., H≈0, σ²/N > 1, herding
  • α > αc : phase asym., H>0, σ²/N → 1, aléatoire
  • α ≈ αc ≈ 0.34 : optimum, σ²/N minimal ≈ 0.28
  • Master curve : universelle en N et M (seul α compte)
  • σ²/N < 1 ↔ corrélations négatives entre agents
  • Auto-organisation spontanée sans coordination explicite

Espace des stratégies

  • M=2 → 2^4 = 16 stratégies
  • M=3 → 2^8 = 256
  • M=5 → 2^32 ≈ 4.3×10⁹ (ne pas stocker !)
  • Algorithme : tirer S vecteurs de 2ᴹ bits par agent
  • Complément de s : toutes les actions inversées
  • Stratégies complémentaires → anti-corrélées → σ²/N < 1

Lien avec les marchés réels

  • r(t) = A(t)/γ : attendance → rendement
  • A > 0 : plus d'acheteurs → prix monte
  • Phase symétrique herding → fat tails des rendements
  • H > 0 → opportunités d'arbitrage (non-EMH)
  • Extensions : contrarians, inaction, autocorrélation
  • Applications : Tobin tax (Cont-Bouchaud), stress tests
🎯 Les 5 points absolument essentiels pour l'oral

1. Bottom-up ≠ Top-down : les ABM laissent émerger les stylized facts au lieu de les postuler. 2. α = 2ᴹ/N est LE paramètre de contrôle du Minority Game — savoir l'interpréter. 3. La transition de phase à αc ≈ 0.34 (S=2) où σ²/N est minimisé = coordination collective spontanée. 4. σ²/N < 1 est possible grâce aux corrélations négatives (anti-coordination émergente). 5. Aucun modèle seul ne reproduit tous les stylized facts — chaque ABM est une fenêtre partielle sur la complexité des marchés.
